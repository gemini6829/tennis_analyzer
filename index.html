🎾 TennisAnalyzer — Firebase Setup

To enable accounts and cloud video storage, you need a free Firebase project. Follow these 5 steps, then paste your config into this file and refresh.

1
Create a Firebase project
Go to console.firebase.google.com → click Create a project → enter a name → follow the wizard to finish.
2
Enable Email/Password sign-in
In the left sidebar go to Security → Authentication. Click Get started, then open the Sign-in method tab. Click Email/Password, toggle it Enable, and hit Save.
3
Create a Firestore database
In the sidebar go to Databases & Storage → Firestore. ⚠️ Important: Firebase has two separate database products — make sure you choose Firestore, not "Realtime Database". Firestore and Realtime Database use completely different rules syntax; if your rules editor shows JSON starting with {"rules": ...} you are in the wrong one.

Click Create database, choose a region, and select either mode. Once created, open the Rules tab. Click inside the editor, select all (Ctrl+A / Cmd+A), delete, then use the Copy button below and paste:
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /users/{userId}/{document=**} { allow read, write: if request.auth != null && request.auth.uid == userId; } } }
Click Publish to save.
4
Enable Storage & configure CORS
In the sidebar go to Databases & Storage → Storage. Click Get started and follow the wizard to create your bucket.
Storage Rules
Open the Rules tab. Click inside the editor, press Ctrl+A / Cmd+A to select all, delete, then paste:
rules_version = '2'; service firebase.storage { match /b/{bucket}/o { match /users/{userId}/{allPaths=**} { allow read, write: if request.auth != null && request.auth.uid == userId; } } }
Click Publish to save.
CORS Configuration
CORS lets the AI models read your uploaded videos. You'll configure it using Google Cloud Shell — a free terminal in your browser, nothing to install.
1. Open Cloud Shell
Go to shell.cloud.google.com and sign in with the same Google account as your Firebase project. Click Continue when prompted to authorize it.
2. Select your project
Your Project ID is shown in Firebase → ⚙ Project Settings under "Project ID". Run:
gcloud config set project YOUR_PROJECT_ID
3. Create the CORS file
echo '[{"origin":["*"],"method":["GET"],"maxAgeSeconds":3600}]' > cors.json
4. Apply it to your bucket
Your bucket name is shown at the top of Databases & Storage → Storage (e.g. your-project.firebasestorage.app). Run:
gsutil cors set cors.json gs://YOUR_BUCKET_NAME
5
Get your config and paste it into this file
Click the ⚙ gear icon next to "Project Overview" → Project settings. Scroll down to Your apps — if you haven't added a web app yet, click the </> (Web) icon to register one. Then select your web app, find the SDK setup and configuration section, choose Config, and copy the object. Open tennis-analyzer.html in a text editor and replace the placeholder FIREBASE_CONFIG at the top of the script:
const FIREBASE_CONFIG = { apiKey: "AIzaSy...", authDomain: "your-project.firebaseapp.com", projectId: "your-project", storageBucket: "your-project.firebasestorage.app", messagingSenderId: "1234567890", appId: "1:123:web:abc", };
Save the file, then refresh this page — the login screen will appear.
